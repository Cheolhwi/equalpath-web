# Plain-language copy and contextual questions

The search heading is now “Find childcare”, followed by “Search by pickup place and care hours.” Vague slogans and internal terms in the saved, comparison, preparation and information dialogs have been replaced with direct descriptions. The page title and printable checklist use the same simpler wording.

The main navigation contains Discover, Compare, Saved and Prepare. Enquiry has been removed. “Prepare questions” remains available from a specific centre’s details and comparison column, and the preparation sheet can return to questions for its own centre. A provider and request are required before the questions dialog opens. Question selection remains scoped to the provider and request.

This changes presentation, not source data, condition checks, fees, registration or centre acceptance. “Matches”, “Doesn’t match” and “Ask the centre” describe the existing three condition states; the official-type age range label is preserved.
