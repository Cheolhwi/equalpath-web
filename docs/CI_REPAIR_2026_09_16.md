## Change

- Run Playwright's bundled full Chromium instead of its default legacy headless shell. Linux CI uses an Xvfb display and Mesa OpenGL, with a WebGL 2 renderer preflight. Local runs retain modern headless mode and `PW_CHANNEL` remains an explicit override. See [Playwright browser documentation](https://playwright.dev/docs/browsers#chromium-new-headless-mode) and [Linux CI guidance](https://playwright.dev/docs/ci#running-headed).
- Keep the original model, textures, loading and animation in CI. Only the landing project uses a 0.25 device scale factor on CI to bound CPU rasterisation; CSS viewport dimensions and all behavioral assertions stay unchanged. Other browser journeys and local visual QA retain full DPI.
- Capture the initial artwork in the existing state observer and pause the slideshow before screenshots; a slow software-rendered screenshot must not race the 6.5-second autoplay dwell.
- Exercise monthly prices and area budgets in regular care. Exercise a published daily fee in the dated details scenario. Add a short-term browser assertion that monthly-only prices remain absent from cards and details.
- Upload browser results, screenshots and retained failure traces for seven days, even when a job fails.
- Support `PW_PORT` for isolated local reproduction without attaching to an unrelated preview.

No application code, production data, test timeouts or deployment logic was changed. No tests were skipped and no failures were suppressed.
