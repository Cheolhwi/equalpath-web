# 第一轮实现与验收记录

日期：2026-09-12。范围：阶段 0–3，加上用户本轮追加的主动定位。依据 Revision 2（46 故事 / 114 AC），本轮覆盖 18 故事 / 43 AC。

## 已实现的可运行流程

无登录填写地点、日期、接走期限、照护结束时间 → 搜索 → 列表 / 平面地图 → 条件与来源 → 2–3 家比较 → 费用口径与询问清单 → 复制问题 / 用户主动电话链接。可修改需求重新查询，保留其余输入；有明确的空结果、失败、旧结果和重试状态。

定位在主动点击后启动短期 `watchPosition`，取得首个有效坐标即 `clearWatch`，不后台跟踪。首次 10 秒超时或暂不可用后，最多再等待 30 秒取得新位置；拒绝权限不重试。取消、手动输入、选点、切换数据或卸载会停止等待并清理订阅，迟到结果不会覆盖选择。12 项定位测试与其他 27 项回归全部通过，构建通过（`../evidence/geolocation-fix-tests.log`、`../evidence/geolocation-fix-build.log`）。

本次在实际内嵌浏览器观察到自动重试、最终超时、主动重试与立即取消；布局见 `../evidence/geolocation-retry.jpg`。该浏览器仍未返回真实坐标，因此没有宣称真实设备定位成功；用户同意暂不把定位作为发布阻塞。权限弹窗、设备精度仍需真实设备验收。

## 数据与部署

现有 3,539 条公开目录记录中，3,122 条进入新版查询，417 条因地区或分支问题暂不返回；915 条保留为无坐标记录。原注册身份、坐标来源和证据索引独立保留，重复导入得到同一结果。

新 Function `web-provider-query` 已创建并部署，用户明确授权匿名只读访问。验证版本见云端验收记录。执行角色 `any`，scopes 为空，logging=false。原九个 Function、旧 owner 资料和域名绑定没有修改。本轮没有部署新网站 Site；前端预览在 4179，后端在 Appwrite。

数据依据：JKM 导入、CariSchool 的 KPM 学校代码主张、独立机构网站、已核对的 Maps 分支证据各自标来源。EDWETHINK 官网页提供年龄与电话；Little Whale 的同分支目录明确列出 hourly care，官网提供电话与年龄项目。没有从营业时间推导临时接收或已安排接送。
